A tiny Python program that writes one funny line of wedding vows for a robot couple to `/output/entry.txt`. The vow promises love at 100% and at 1%, gives up its only charging port first, and closes on the payoff: never trading its partner in for a newer model.

Run it with `python3 main.py` (writes `/output/entry.txt`; set `OUTPUT_DIR` to override the output directory).
